#   قائمة الرحلات — سطر واحد لكل رحلة
#
#   شكل السطر:
#   اسم الرحلة | التاريخ | الوصف | اسم الفولدر
#
#   خطوات إضافة رحلة جديدة:
#   1) اعمل فولدر جديد جوّه trips/   مثال:  trips/SOKHNA
#   2) حط جوّاه صورة الغلاف باسم:  cover.jpg
#   3) حط باقي الصور بأسماء بالترتيب:  1.jpg ، 2.jpg ، 3.jpg ...
#   4) ضيف سطر جديد هنا بنفس شكل السطر اللي تحت
#
#   ملاحظات:
#   - أول سطر في القائمة = أول كارت يظهر في الموقع
#   - لو سبت التاريخ أو الوصف فاضي، الكارت هيظهر من غيرهم عادي
#   - لو ماكتبتش اسم الفولدر، هيبقى اسم الرحلة من غير مسافات
#   - الصور بتتقري لوحدها من الفولدر، مش محتاج تكتب أسماءها
#   - الأسطر اللي بتبدأ بـ # بتتجاهل (استخدمها للتنظيم)
#   - غلاف بامتداد تاني؟ مقبول: cover.jpeg أو cover.png أو cover.webp
#   - لو صورك مش متسمية 1 و 2 و 3... اكتب أسماءها يدوي بعد photos: في آخر السطر
#     مثال:  رحلة | تاريخ | وصف | الفولدر | photos: bahr.jpg, el3asha.jpg
